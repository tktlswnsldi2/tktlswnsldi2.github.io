# 🎓 Kangwon National University Portfolio (이영준)

강원대학교 강릉캠퍼스 회계학과 2학년 **이영준**의 개인 홈페이지 & 학술 포트폴리오 저장소입니다.

🌐 **라이브 웹사이트 주소**: [https://tktlswnsldi2.github.io](https://tktlswnsldi2.github.io)

---

## ✨ 웹사이트 특징

- **반응형 글래스모피즘 디자인**: 다크/라이트 모드 지원, 은은한 배경 오르브 애니메이션
- **타이핑 애니메이션**: 전공 분야 및 관심사 타이핑 효과
- **사진 없는 미니멀 & 세련된 엠블럼 UI**: 강원대학교 및 회계학과 상징 카드 적용
- **전공 역량 쇼케이스**: 재무회계, 원가관리회계, Excel 고급 분석, 전산세무회계 등
- **학술 분석 및 프로젝트**: 재무제표 비교 분석, 엑셀 손익 관리 템플릿, CVP 원가 분석 등
- **손쉬운 내용 수정**: `assets/js/data.js` 파일만 수정하면 모든 내용 즉시 반영

## 📁 파일 구조


## 🚀 배포 및 수정 방법

### 1. 내용 수정하기
[assets/js/data.js](assets/js/data.js) 파일을 열어 새로운 프로젝트, 수강한 전공 과목, 취득한 자격증 등을 자유롭게 추가/수정하실 수 있습니다.

### 2. GitHub Pages 배포하기
```bash
git add .
git commit -m "feat: 강원대학교 회계학과 이영준 포트폴리오 업데이트"
git push origin main
```
푸시 후 약 1~2분 뒤 `https://tktlswnsldi2.github.io`에서 확인하실 수 있습니다.
